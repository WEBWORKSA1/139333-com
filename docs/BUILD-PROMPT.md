## Phase 3 — Lucky-number engine (`assets/js/engine.js`)

1. Build the digit table 0–9, with Chinese, pinyin, sound-alike and weight (8 +5, 9 +3.5, 6 +3, 2 +2, 3 +1.5, 1 +1, 5 +0.5, 0/7 0, 4 −6).
2. Build a table of 40+ combinations with score impact:
   - positive: 168, 518, 1314, 5201314, 888, 8888, 666, 999, 139, 333…
   - negative: 14, 74, 748, 514, 250, 44…
3. Detect patterns: AAA / AAAA / AAAAA tails, ABAB, AABB, ABBA, rising and falling straights.
4. `analyze(number)` works as follows:
   - start at 50;
   - add combination matches (longest first, no overlaps, weighted toward the tail);
   - add digit weights (the last 4 digits ×1.4);
   - add +6 if the number has no 4, −8 if it ends in 4, +4 if it ends in 8 or 9;
   - add pattern bonuses;
   - clamp to 1–99;
   - grade: Supreme, Very lucky, Favourable, Neutral, Unfavourable.
5. `valueTier()` returns Standard, Silver, Gold, Platinum or Legendary, with indicative CNY bands and a real-sale note.
6. Add a zodiac function (year → animal, element, yin/yang, lucky digits), compatibility (triads, six harmonies, clashes) and a deterministic number of the day.

**Accept:** unit checks pass —
- `13933331688` scores ≥ 85;
- `13844748` scores < 40;
- `13933338888` returns Platinum.

4. A **blurred "unlock full report" teaser with an email form**, which is the lead magnet. On submit it reveals the digit-by-digit table.
5. Share and "find a luckier number / sell this number" CTAs.

Tools to build:

**Accept:** all tools work offline in the browser with no console errors, and results are announced via `aria-live`.
